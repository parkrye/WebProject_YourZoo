# YourZoo

동물원 운영 시뮬레이터. **플레이어가 직접 그린 동물**을 우리에 배치하고,
그 동물이 습성에 따라 살아 움직이는 모습을 관찰하며 동물원을 재건한다.

## 실행

**`YourZoo 실행.bat` 을 더블클릭**하면 된다. 처음 한 번은 준비물을 내려받느라 몇 분 걸린다.

창에 접속 주소가 뜬다. `같은 와이파이` 주소를 쓰면 **같은 네트워크의 다른 기기**(폰, 노트북)에서도
들어올 수 있다. 처음 실행하면 Windows 방화벽이 물어보는데 `개인 네트워크` 를 체크하고 허용해야 한다.

개발할 때는:

```bash
npm install
npm run dev
```

검증용으로 서버를 하나 더 띄울 때는 `npm run preview:test` (**29877**) 를 쓴다.
29876 은 사용자가 배치 파일로 띄우는 자리이므로 건드리지 않는다.

포트는 **29876** 으로 고정돼 있다(`vite.config.ts`). 흔한 개발 포트를 피해 골랐고,
점유돼 있으면 조용히 다른 포트로 옮기지 않고 실패한다 — 자동 이동을 허용했더니
좀비 dev 서버가 14개까지 쌓여서 옛 코드를 보고 있으면서 원인을 엉뚱한 데서 찾은 적이 있다.

## 현재 상태 — M0 ~ M10

동작하는 것:
- 타이틀 → 우리 화면 전환
- 3레이어 합성 (하늘 / 바이옴 / 펜스) + 시간대 크로스페이드
- 게임 시계 (1일 180초, 낮 → 저녁 → 밤)
- 명성 비례 손님 배치 + 절차적 보빙 이동
- 좌우 우리 순회, 상세보기 진입 시 펜스 하강 연출
- 스프라이트 비트맵 폰트 (글리프 메트릭 자동 측정)
- 옵션 / 운영 현황 팝업 (9-슬라이스 프레임)

- 그림판: 연필 6색 / **채우기** / 지우개 / undo·redo / 모두 지우기
- 새 게임 시작 시 동물원 이름 짓기
- 요청서: 이름, **그림 템플릿 8종**(사슴·토끼·악어·앵무새·올빼미·물고기·거북·자유),
  서식지 선택, TYPE·CUSTOM·RANDOM 습성 설정
- 배송(1일) → 창고 → 상세보기 트레이에서 **드래그해 배치** → 창고 회수 → 판매
- 커서로 동물을 집으면 습성·매력도 카드가 열린다
- 그림은 알파 트림 후 PNG 로 IndexedDB 에 저장

- 동물 AI: 자체 구현 BT. 위협 회피 → 휴식 → 무리 짓기 / 프롭 관찰 / 배회 우선순위
- 습성이 행동을 바꾼다 — 겁이 많으면 더 먼 거리에서 도망치고, 활동성이 낮으면 자주 쉰다
- 서식지별 로밍 박스 구속, 프롭 회피, y 정렬로 프롭 뒤 가림
- **유형별 부위 움직임** — 이미지를 띠로 나눠 밀어서 다리·날개·꼬리가 따로 움직인다.
  파츠를 자르지 않으므로 이음매가 없다

- 자정 정산: 입장료 · 관람 수입 · 사육비 · 명성 증감, 결과 팝업
- 상세보기 확대(4단계)와 손바닥 팬
- 우리 해금 (DESERT 500G / ICE 1500G)
- localStorage 세이브 + 타이틀 CONTINUE
- 모달이 열려 있으면 시계 정지 (그림 그리는 동안 하루가 지나가지 않는다)

- NPC 의뢰: 매일 게시되는 조건부 의뢰. 맞는 동물을 넘기면 골드와 명성 보상

- 첫 플레이 튜토리얼 4단계
- 사운드: BGM 5종 · 스팅어 2종 · 환경음 3종 · 클릭음 2종 ([docs/04-audio.md](docs/04-audio.md))

아직 없는 것:
- **8×3 스프라이트 시트 연동** — 외부 SDK 대기. `SheetRenderer` 와
  `Animal.spriteSheet` 는 준비돼 있어 팩토리 분기만 타면 된다

## 개발용 검증 페이지

```
http://localhost:5173/?dev=assets
```

폰트 알파 컷아웃 · GUI 36칸 슬라이싱 · 팝업 9-슬라이스를 한 화면에서 눈으로 확인한다.
**이 페이지가 깨지면 그 위의 모든 UI가 깨진다.** 에셋 관련 작업 후에는 항상 여기부터 본다.

## 에셋 파이프라인

```bash
python scripts/prepare-assets.py <원본 디렉터리>
```

원본을 게임이 쓰는 형태로 전처리해 `src/assets/images/` 에 넣는다.
전처리 결과만 리포에 두고 원본은 두지 않는다 (`.gitignore` 의 `assets-source/`).
알파가 없던 셋(`bg_area_ice`, `sprite_prop_desert`, `sprite_human_visitor`)의 검은 배경을
여기서 한 번만 지운다. 런타임에는 배경을 손대는 코드가 없다.

`public/` 은 쓰지 않는다. 이미지는 `manifest.ts` 가 import 하고 번들러가 해시 URL을 붙인다.

## 에셋 제약 (중요)

1. **폰트에 A-Z / 0-9 밖에 없다.** 게임 내 모든 텍스트는 영문 대문자. 한글·소문자·문장부호 불가.
2. **시트의 알파는 눈이 아니라 채널로 확인할 것.** 뷰어가 알파를 무시하고 RGB 만 보여줘서
   투명 배경을 불투명으로 오판한 적이 있다. 그 결과 글자 외곽선이 통째로 지워졌다.
3. **손님 스프라이트가 정지 1프레임이다.** 걷기는 절차적 보빙으로 만든다.
4. **동물 스프라이트는 향후 외부 SDK가 8×3(8프레임 × IDLE/MOVE/SIGNATURE) 시트로 생성한다.**
   그때까지는 그린 그림 1장을 절차적으로 변형한다. `render/animal/AnimalRenderer` 인터페이스로 격리되어 있어
   교체 비용은 사실상 0이다.
