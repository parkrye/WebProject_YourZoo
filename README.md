# YourZoo

동물원 운영 시뮬레이터. **플레이어가 직접 그린 동물**을 우리에 배치하고,
그 동물이 습성에 따라 살아 움직이는 모습을 관찰하며 동물원을 재건한다.

```bash
npm install
npm run dev
```

## 현재 상태 — M0 / M1 / M2

동작하는 것:
- 타이틀 → 우리 화면 전환
- 3레이어 합성 (하늘 / 바이옴 / 펜스) + 시간대 크로스페이드
- 게임 시계 (1일 180초, 낮 → 저녁 → 밤)
- 명성 비례 손님 배치 + 절차적 보빙 이동
- 좌우 우리 순회, 상세보기 진입 시 펜스 하강 연출
- 스프라이트 비트맵 폰트 (글리프 메트릭 자동 측정)
- 옵션 / 운영 현황 팝업 (9-슬라이스 프레임)

- 그림판: 연필 6색 / 지우개 / 모두 지우기 / undo·redo / 완성
- 요청서: 이름 입력, 그림, TYPE·CUSTOM·RANDOM 습성 설정, 제출 시 비용 차감 후 우리에 배치
- 그림은 알파 트림 후 PNG 로 IndexedDB 에 저장

아직 없는 것: 동물 AI(BT)와 우리 안 렌더, 프롭, 경제 정산, 세이브/로드, NPC 의뢰
→ `docs/03-roadmap.md` M3~ 참조.

## 개발용 검증 페이지

```
http://localhost:5173/?dev=assets
```

폰트 알파 컷아웃 · GUI 36칸 슬라이싱 · 팝업 9-슬라이스를 한 화면에서 눈으로 확인한다.
**이 페이지가 깨지면 그 위의 모든 UI가 깨진다.** 에셋 관련 작업 후에는 항상 여기부터 본다.

## 에셋 제약 (중요)

1. **폰트에 A-Z / 0-9 밖에 없다.** 게임 내 모든 텍스트는 영문 대문자. 한글·소문자·문장부호 불가.
2. **폰트 시트 배경이 불투명하다.** `src/assets/cutout.ts` 의 플러드필로 런타임 1회 제거한다.
3. **손님 스프라이트가 정지 1프레임이다.** 걷기는 절차적 보빙으로 만든다.
4. **동물 스프라이트는 향후 외부 SDK가 8×3(8프레임 × IDLE/MOVE/SIGNATURE) 시트로 생성한다.**
   그때까지는 그린 그림 1장을 절차적으로 변형한다. `render/animal/AnimalRenderer` 인터페이스로 격리되어 있어
   교체 비용은 사실상 0이다.
